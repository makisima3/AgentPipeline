# Выбор рабочей папки сервера

В создании проекта (включая первое знакомство) и настройках кнопка **Обзор…** открывает общий браузер каталогов. Он показывает папки ПК, на котором работают сервер и агенты. Загрузка файлов с телефона и системный диалог на ПК не используются. Ручной ввод полного пути в формах сохранён.

**Диски и корни** показывает логические диски Windows и домашнюю папку учётной записи сервера; на других ОС — `/` и домашнюю папку. Сетевой ресурс можно открыть по полному UNC-пути, если он доступен этой учётной записи. Переходы — нажатием на папку, **Выше** либо вводом пути и **Перейти**. Из корня диска **Выше** возвращает к списку дисков. Пустую папку можно выбрать.

Текущий путь показан отдельно, длинные строки переносятся, список прокручивается независимо от кнопок. **Выбрать папку** повторно проверяет текущий каталог и подставляет путь в исходную форму. Для сохранения проекта используется её прежняя кнопка **Создать/Сохранить**. Отмена, Escape и системная «Назад» Android закрывают только браузер каталогов, сохраняя введённые данные. Повторное открытие начинает с пути из формы. После редактирования строки пути сначала нажмите **Перейти**.

При ошибке текущая форма сохраняется, выбор блокируется; можно исправить путь, открыть корни или повторить запрос после восстановления связи. Удаление папки между выбором и сохранением проверяется также при создании/изменении проекта.

При открытой клавиатуре окно временно сокращает список и скрывает пояснение/навигацию, оставляя строку пути, **Перейти**, состояние и кнопки выбора/отмены доступными. После скрытия клавиатуры полный вид возвращается.

## API и ограничения

`POST /api/folders` принимает JSON `{ "path": null }` для списка корней либо `{ "path": "C:\\Projects" }` для папки. Ответ: `{path, parent, entries:[{name,path}]}`. У списка корней `path/parent=null`, у корня диска `parent=null`. Файлы не возвращаются, ссылки на каталоги доступны в рамках прав учётной записи сервера. Корни перечисляются без обращения к каждому диску; отсутствие прав/носителя обнаруживается при открытии.

`server/folders.py` проверяет тип, абсолютность, управляющие символы и длину пути, отвергает служебные пути устройств Windows/ADS. Переменные окружения и `~` не раскрываются. Для длинных Windows-путей внутреннее чтение использует extended-length форму; в UI/БД остаётся обычный путь. Регистр и Unicode имён сохраняются. Доступ определяется правами процесса сервера, дополнительных ограничений по папкам нет; размещение и доступ к самому трекеру не меняются.

Просмотр только читает файловую систему через `os.scandir`, без shell, создания папок, удаления или запуска команд из пути. Операция выполняется в отдельном скрытом процессе stdlib Python, путь передаётся JSON через stdin. Лимит — четыре одновременных процесса, пять секунд на операцию; процесс при тайм-ауте завершается через общий `runtime`. Более 20 000 вложенных каталогов дают понятную ошибку с предложением указать точный путь; сохранение вручную введённого пути не перечисляет содержимое. Клиент отменяет устаревшие запросы и ограничивает ожидание 12 секундами. Ошибки: 400 неверный путь, 403 права, 404 отсутствующий каталог/файл вместо папки, 413 слишком много каталогов, 429 заняты слоты, 503 недоступный диск, 504 тайм-аут. Старый `POST /api/pick-folder` удалён (404), tkinter не вызывается.

## Проверки

```powershell
python -m unittest discover -s tests -p test_folders.py -v
python tests/folders_demo.py
# Порт и временная папка: output/playwright/task-45/demo.json
npx --yes --package @playwright/cli playwright-cli -s=folders open http://127.0.0.1:<порт> --browser=msedge
npx --yes --package @playwright/cli playwright-cli -s=folders run-code --filename tests/folders_ui.js
python tests/android_folders_check.py --adb <путь-к-adb>
```

Демо копирует сервер и web во временную папку, использует отдельную БД и тестовые каталоги; циклы агентов и Telegram не запускаются. API-тесты покрывают реальное чтение и тайм-аут процесса, валидацию, длинный путь при создании/изменении проекта, удаление и перевод ошибок прав через заглушку (ACL машины не меняются). Web-проверки — 390/1280 px, создание, настройки, мастер, корни C/D, пустой/длинный путь, отмена, прокрутка, Escape, мост «Назад», потеря связи/повтор и отказ при подтверждении.

Android-скрипт работает только с отдельным эмулятором и установленным APK: системный ввод, клавиатура, прокрутка, выбор/отмена, «Назад» и повторное подключение. Физический телефон и особенности его клавиатуры/прошивки этим не проверяются. После проверки остановите свои демо-процессы, браузер и эмулятор; боевой сервер не трогать.
